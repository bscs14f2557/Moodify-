 Moodify - Mood Based Songs App 

Moodify is a simple desktop music player built in Java. Instead of searching through long lists, this app helps you find music that matches your current mood (like Happy, Sad, Rainy, Motivation, or Qawwali). It supports playlists for both English and Urdu/Hindi songs.

 Features
- Mood Selection: Click on your mood to see matching songs.
- Dual Languages: Separate playlists for English and Urdu/Hindi music.
- Audio Playback: Plays music smoothly using local audio files.
- Clean UI: Designed with a stylish Black and Gold theme.

 Tech Stack
- Language: Java SE
- GUI Framework: Java Swing (JFrame, JButton, JList)
- Audio API: Java Sound API (javax.sound.sampled)
- IDE used: Eclipse

 OOP Concepts Used
This project was created to practice core Object-Oriented Programming principles:
- Abstraction: Hiding complex logic using Java Interfaces.
- Inheritance: Creating a base `Media` class that the `Song` class inherits from.
- Polymorphism: Using a single Playlist Window that dynamically changes based on any selected mood.
- Encapsulation: Keeping data secure by making variables private and using getters/setters.

 How to Run
1. Make sure you have Java installed on your computer.
2. Download or clone this repository.
3. Open the project in your IDE (like Eclipse or IntelliJ).
4. Run the `MoodifyGUI.java` file.
5. (Note: Make sure your local music files are in `.wav` format).
